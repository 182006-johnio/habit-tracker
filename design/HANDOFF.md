# UI デザイン引き渡し

このフォルダは習慣化トラッカー v2 の UI デザインだ。仕様は spec-v2-habit-tracker.md（CLAUDE.md に追記済みの分）に従い、見た目だけをこのフォルダから取る。

## ファイルの読み方

`*.dc.html` はデザインツールの独自形式で、そのままでは動かない。`<x-dc>` `<sc-for>` `<sc-if>` `{{...}}` や末尾の `class Component extends DCLogic` はツール用の記法なので、コピーせず、レイアウト・余白・色・文字サイズの参照として読むこと。実装は vanilla JS / HTML / CSS で書き直す。

中の数字や習慣名（腕立て伏せ 23日連続など）はすべて仮のサンプル。実データから計算して表示する。

## 共通ルール

- フォント：`-apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', sans-serif`。数字は `font-variant-numeric: tabular-nums`
- 角丸：カード 20px、ボタン・入力欄 12〜14px、チップとゲージは全丸
- タップできる要素は 44px 以上
- 上下はセーフエリア（env(safe-area-inset-*)）を足す。デザインの上余白 52〜56px はステータスバー込みの値
- ○△× は文字ではなく SVG の図形（円・三角・バツ）で描く。Main.dc.html の SVG をそのまま使ってよい
- 入力欄の文字は 16px 以上（iPhone のズーム防止）

## 状態の出し分け（Main のカード）

- 通常：稲妻＋連続日数を大きく
- 週モード（仕様の getWeekMode が true）：「今週 n / 7」を大きく、曜日ドット7つ、連続日数は小さく併記
- 66日達成：「66日達成」バッジ＋連続日数を小さめに
- 3つとも、復帰回数・累計ゲージ・今日の○△×ボタンは共通で持つ

## 進め方

仕様書の実装順どおり、UI はデータ層と判定ロジックが終わってから着手する。画面ごとに実装し、1画面終わるたびに確認を待つこと。
